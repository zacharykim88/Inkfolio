# InkFolio 开发修订

2026-10-24 · 基于上一开发修订；正式版本仍为 v1.2.0，尚未发布。

## 本次修改

- 点击外观调整中的预览画面，以设备原始分辨率全屏显示；再次点击或按键返回。全屏使用当前未保存的草稿，返回保留调整，不触发保存。
- 三种小票皮肤的品牌、单日天气及日期按首行实际字形高度居中；字号、字重、横向对齐及长天气换行规则保留，其他数据行沿用字体基线对齐。
- 打开墨笺设置时关闭底层 KOReader 原菜单；在任意一级墨笺菜单外点击，一次收起菜单，该次点击不向底层传递。返回操作继续逐级返回。
- 封面卡片底色新增“自动／白色／黑色”，独立保存，未设置时使用自动。自动只采样卡片外缘附近的实际背景：偏浅使用黑底白字，偏深使用白底黑字。文字、辅助文字、边框及进度条同步适配；手动选择固定底色时不执行检测。
- 封面未铺满区域的底色保留原有白色／黑色选择，不增加自动模式。

## 安装

完全退出 KOReader，将 `2-inkfolio.lua` 覆盖到 `koreader/patches/` 内同名文件，再重新启动。保留已有字体、设置和阅读数据，备份请放在 patches 目录以外。

选择“外观调整 → 封面 → 卡片底色”设置自动或固定配色；点击上方预览画面可全屏查看。

8561 项通过、0 项失败。已用真实 KOReader 组件及字体检查 600×800、758×1024、1072×1448、1440×1920 与 1920×1440 的布局、原生点击事件、菜单层级、草稿保存与取消、卡片自动及手动配色；软件渲染已查看，尚待 Kobo Sage 实机验证。本次没有改变联网规则；联网回归使用模拟事件与保存的响应样本，未做实时联网测试。

## 重跑检查

准备 KOReader Linux 原生模拟运行目录，设置 `KOREADER_RUNTIME` 后运行：

```sh
KOREADER_RUNTIME=/absolute/path/to/koreader python3 run_checks.py
```

测试结果及原生截图写入 checks/；每个子进程使用独立临时设置目录。
