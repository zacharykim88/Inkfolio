# InkFolio D23

基于 KOReader Book Receipt 重构扩展的阅读信息卡，支持多种皮肤、阅读统计、天气与截图。

[English](README.en-US.md)

本轮以 D22 为基础，合并独立的 D20“纸上”功能，完成已确认待办。正式版本仍为 1.2.0，发布日期仍为 2026-10-23；本目录仅保存开发代码，未打包、未发布 Release。

## 本轮修改

- 修正英文天气文字与图标对齐，保留城市／今日或明日 → 图标 → 温度的顺序。
- 将信息弹窗的查找入口、查找窗口、下一处与结果提示改为英语，搜索后重建的按钮也保持英语，不修改 KOReader 全局语言。
- 英文周柱状图从周日开始，日期、时长和字数同步调整；中文周图、周摘要与阅读目标仍从周一开始。
- 去除像素皮肤四边灰点，保留黑色轮廓。
- 封面、纸上的英文书名使用 KOReader 自带的 Noto Serif Italic；作者、章节和统计保持直立，中文书名保留原字体。现代、小票与像素保留各自字体风格，简介保持直立。
- 合并“纸上”皮肤，将当前阅读页虚化作为背景，信息卡片保持清晰。默认白底黑字，也可手选深灰底白字，不使用自动配色。
- 精简中英文项目介绍，保留上游来源、署名、致谢与许可；复查英文词典，统一月榜等用词。

## 纸上

在阅读中打开“工具 → InkFolio → 外观调整 → 纸上”。非阅读界面此选项灰显；已选纸上时在其他界面锁屏，本次使用最近一本书的封面，不改变已选皮肤。

阅读背景通过原生阅读视图重新绘制，不复制设置菜单。先虚化背景，再绘制信息卡片；预览、全屏预览、截图与休眠显示共用这一流程。调整预览时复用已虚化的背景，避免重复处理。虚化强度以近看可辨、随意一瞥难辨为目标，实际观感与耗时仍需 Sage 验收，不能保证内容无法被识别。

纸上与封面共用卡片内容、宽度、字号及单日天气选择，卡片颜色分别保存。封面自动配色保持灰度阈值 150 和 #333333 深灰色，封面未铺满区域的底色逻辑保持原样。

## 语言和外观

“工具 → InkFolio → 语言”可选“简体中文／English”。选择立即保存，不改变书籍内容、用户文字或 KOReader 全局语言。英语采用美式拼写、日期与数字格式。原生键盘和文件夹选择器仍使用 KOReader 的语言。

外观设置点击预览可全屏，再次点击返回；保存后应用调整，取消或返回放弃本次修改。所有运行词典和天气图标都嵌入补丁，无需新增运行文件；英文书名字体使用 KOReader 自带字体。
