# InkFolio 开发修订

2026-10-24 · 基于已确认实机通过的上一开发修订 · 正式版本仍为 v1.2.0，尚未发布。

## 本次修改

- 封面皮肤不支持的图书与榜单、阅读图表、月榜设置、阅读目标及底部文字菜单灰显；不会清除原设置，切回其他皮肤后恢复可用。
- 封面天气左对齐、日期右对齐，保持同一行；今日／明日互斥，也可都不显示。封面天气选择单独保存，其他三种皮肤仍可双选。首次沿用原选择；原来双选时，封面默认今日。

- 新增封面皮肤：封面等比例完整显示并居中，空余区域可选黑／白；中央为不透明白色圆角卡片，默认宽度为屏幕50%。
- 卡片固定显示书名、作者、章节、百分比和页码，复用已勾选的其他进度、数字摘要及日期；天气单选今日或明日，与日期同行。卡片按用户确认范围展示，不放置评分、出版社、目标、趋势图或月榜；这些模块及数据继续保留在其他皮肤中。
- 卡片宽度、字号、封面底色独立保存，已有宽度设置保留；缺失作者、章节或封面时明确提示；长内容按实际宽度换行，超出屏幕时禁止保存或导出该布局。
- 现代皮肤书名字号由44提高为55。
- 联网按任务到期执行，取消固定45秒巡检与3分钟周期书库扫描。

## 联网规则

| 项目 | 自动规则 |
| --- | --- |
| 天气 | 成功后6小时到期，跨日重新检查；一次请求缓存今日与明日。切城或勾选缺少缓存的日期可立即获取。失败后等待下一个到期点，手动可重试。 |
| 书库 | 启动、文件管理器进入／刷新或更换目录时扫描；打开书籍只排入当前书。已有任务结束后执行排队中的扫描。 |
| 图书 | 完整缓存长期使用；待确认与暂不采用的书跳过。失败间隔至少30分钟，每本每天最多3次自动尝试；手动不占自动次数。 |
| 月榜 | 每天最多检查一次新一期；取得本月发布的完整榜单后暂停至下月。手动刷新可强制重取。 |
| 取消 | 只暂停当前请求所属模块，本次唤醒不自动重启；其他模块按各自规则继续。重新唤醒清除本次暂停。 |
| 网络错误 | 连续3次网络请求错误暂停自动联网；联网成功事件或明确手动获取可以恢复。 |

自动任务只使用已连接的网络；手动“更新信息”仍可在用户确认后开启 Wi-Fi。休眠不执行任务，不为联网主动唤醒设备。没有到期任务时不设置短周期检查。

## 安装

完全退出 KOReader，将 `2-inkfolio.lua` 覆盖到 `patches/` 内同名文件，然后重新启动。补丁备份请放在 patches 之外。已安装 v1.2.0 字体的用户无需补装字体。已有设置、匹配记录、天气、统计与阅读记录保留。

在“外观调整”中选择“封面”。此皮肤只显示卡片宽度、卡片字号和封面底色控件，完整封面不受原小封面开关影响。

## 重跑检查

准备带 luajit 的 KOReader Linux 原生模拟运行环境，并为 `KOREADER_RUNTIME` 设置其运行目录（其中应包含 `luajit`、`frontend/`、`plugins/` 等）。安装所需的既有字体后，运行：

```sh
KOREADER_RUNTIME=/absolute/path/to/koreader python3 run_checks.py
```

运行结果与原生渲染图写入本目录的 checks/；每个子进程使用独立临时设置目录。
