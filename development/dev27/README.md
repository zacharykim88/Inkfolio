# InkFolio D27

基于 KOReader Book Receipt 重构扩展的阅读信息卡，支持多种皮肤、阅读统计、天气与截图。

[English](README.en-US.md)

本轮移除纸上皮肤，修正天气刷新失败后的有效缓存显示，并将“顶部信息”菜单更名为“天气与日期”。正式版本仍为 1.2.0，发布日期仍为 2026-10-23；本目录仅保存开发代码，未发布 Release。本轮仅交付 Lua，不更新完整包。

## 本轮修改

- 取消纸上皮肤，删除阅读背景抓取、淡化、专用预览与配色代码。旧设置中选中的纸上自动迁移为封面，删除纸上专用底色，保留封面及其他皮肤的设置。
- 天气卡片优先显示同一城市当天获取的有效预报，刷新失败或正在刷新均不遮盖缓存；部分日期刷新成功时，不再丢弃另一日期已有的有效预报。无有效缓存时仍明确显示获取状态或失败。
- “信息来源与状态”继续如实记录最近尝试、结果与失败原因。缓存只用于当前获取日期和对应预报日期，不跨城市或跨获取日套用。
- “显示内容 → 天气与日期”不再按位置命名；封面的天气与日期位于卡片底部，其他三款皮肤位于顶部。中英文菜单、帮助与说明同步。

## D23 已有功能

- 修正英文天气文字与图标对齐，保留城市／今日或明日 → 图标 → 温度的顺序。
- 将信息弹窗的查找入口、查找窗口、下一处与结果提示改为英语，搜索后重建的按钮也保持英语，不修改 KOReader 全局语言。
- 英文周柱状图从周日开始，日期、时长和字数同步调整；中文周图、周摘要与阅读目标仍从周一开始。
- 去除像素皮肤四边灰点，保留黑色轮廓。
- 封面英文书名使用 KOReader 自带的 Noto Serif Italic；作者、章节和统计保持直立，中文书名保留原字体。现代、小票与像素保留各自字体风格，简介保持直立。
- 精简中英文项目介绍，保留上游来源、署名、致谢与许可；复查英文词典，统一月榜等用词。

## 封面与天气

外观调整可选小票、像素、现代、封面四款皮肤。封面卡片颜色可选自动、白色或深灰；自动配色仍按卡片四周平均灰度 150 为阈值，深灰为 #333333。封面未铺满区域的底色仍提供白色／黑色选择。

封面只显示今日或明日中的一项天气，与日期位于卡片底部；其他皮肤可同时显示两日天气，位于顶部。天气每6小时更新，刷新失败时继续使用当天有效缓存，最近尝试失败仍可在“信息来源与状态”中查看。

## 语言和外观

“工具 → InkFolio → 语言”可选“简体中文／English”。选择立即保存，不改变书籍内容、用户文字或 KOReader 全局语言。英语采用美式拼写、日期与数字格式。原生键盘和文件夹选择器仍使用 KOReader 的语言。

外观设置点击预览可全屏，再次点击返回；保存后应用调整，取消或返回放弃本次修改。所有运行词典和天气图标都嵌入补丁，无需新增运行文件；英文书名字体使用 KOReader 自带字体。
