# InkFolio D21

以 D19 为基线，新增可选天气图标与简体中文／美式英语切换。正式版本号仍为 1.2.0，发布日期仍为 2026-10-23。

[English (United States)](README.en-US.md)

## 安装

用本目录的 `2-inkfolio.lua` 覆盖 KOReader `patches` 目录中的同名文件，完全退出并重启 KOReader。继续使用 D19 已安装的字体，无需额外安装图标或语言文件。保留原设置、天气缓存、图书匹配与阅读数据。

## 天气图标

工具 → InkFolio → 显示内容 → 顶部信息 → 天气显示，可选“文字”或“图标”，默认沿用文字显示。四款皮肤共用一套 24×24 网格、圆角线条的黑白矢量图标，跟随界面比例缩放，并适配封面卡片的白底／深灰底配色。

12 类图形覆盖晴、多云、阴、阵雨、雨、雷雨、雪、雨夹雪／冻雨、冰雹、雾、霾及沙尘。未知或混合状态保留文字，不错误归类。温度、城市、日期与今日／明日选择维持原功能。切换显示方式不发起联网请求；获取中或失败时显示文字提示，不显示旧天气图标。

## 语言

工具 → InkFolio → 语言 → 简体中文 / English (United States)。立即保存并重建 InkFolio 设置菜单，无需重启，不修改 KOReader 的全局语言。

英语覆盖四款皮肤、设置、弹窗、帮助、关于、更新说明、诊断、天气名称与地点显示。按英语习惯调整日期、时长、数字和文字长度。书名、作者、章节、联网获取的图书内容及用户输入保留原文。

英语字数目标以“千字／千词”输入整数，例如 25 表示 25,000；中文仍以万字输入，例如 2.5 表示 25,000。两种语言使用相同的存储值，切换不改变已设目标。统计方法不变：中文按字、英文按单词计数。

## 基线与验证

保留 D19 的小票、像素、现代、封面四款皮肤及紧凑外观设置。封面自动配色继续使用平均灰度阈值 150，深灰色为 #333333。D20 的“纸上”皮肤独立保存在 dev20，不属于本开发包。

软件验证详见 [VALIDATION.md](VALIDATION.md)。本开发包尚待 Kobo Sage 实机验收，不发布正式 Release。

## 开发

运行 `KOREADER_RUNTIME=/path/to/koreader python3 run_checks.py`。测试使用真实 KOReader 原生字体、控件、图像渲染和本地 SQLite，不连接天气或图书服务。

补丁运行所需的英文词典和图标均嵌入单文件。`localization/en-US.json` 为源码词典的审核快照，不是额外运行依赖。图标为本项目原创 SVG，沿用项目 GPL-3.0 许可。
