# InkFolio 开发修订

2026-10-25 · 以 D16 为基线；正式版本仍为 v1.2.0，尚未发布。

本次只将封面卡片自动配色阈值从127.5调整为150。周边采样点平均灰度大于等于150时使用深灰底、浅色文字，小于150时使用白底、黑色文字。平均值直接比较，不四舍五入。采样范围、取点方式、手动选项和所有其他功能沿用 D16；深灰底保留 #333333。

## 安装与验证

完全退出 KOReader，将 `2-inkfolio.lua` 覆盖到 `koreader/patches/` 同名文件后重新启动。

相关检查2310项通过、0项失败；包含等于150、略低于150的混合像素平均值、自动与手动配色及五种分辨率。软件渲染已查看，当前阈值效果待 Kobo Sage 实机确认。

```sh
KOREADER_RUNTIME=/absolute/path/to/koreader python3 run_checks-dev16.py
```

复用 D16 的针对性检查入口；完整回归入口仍为 `run_checks.py`。
