# InkFolio 开发修订

2026-10-25 · 以 D19 为基线，正式版本仍为 v1.2.0，尚未发布。

## 纸上皮肤

- 以当前实际阅读页为背景，保留阅读排版，复用封面皮肤的中央阅读信息卡片、宽度、字号、内容及天气单选规则；不包含外观编辑器或设置菜单。
- 卡片默认白底黑字，可手选与封面一致的深灰底色（#333333），不提供自动配色。纸上颜色独立保存，封面原有自动及固定配色保留。
- 仅在阅读中允许选择“纸上”。主页等非阅读界面中的“纸上”选项灰显；已选择时保持选中状态。
- 已选纸上而在非阅读界面锁屏时，本次使用最近一本书及封面皮肤原有设置，不改变已选皮肤；回到阅读中继续使用纸上。此时外观编辑器预览本次封面显示，纸上配色项灰显；如需调整封面配色，可明确选择封面皮肤。
- 阅读页背景只在生成画面时绘制，不额外联网、定时刷新或保存整页背景文件。最近书籍已移动、删除或没有记录时沿用明确提示。

## 安装

完全退出 KOReader，覆盖 `koreader/patches/2-inkfolio.lua` 后重新启动。在阅读页打开“外观调整”，选择“纸上”。已有字体和阅读数据保留。
