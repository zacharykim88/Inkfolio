# 墨笺 v1.1.0 开发阶段 · 设备实际运行截图

用户于2026-10-13在Kobo Sage上提供，原图分辨率1440×1920。界面由设备内运行的KOReader绘制并截取，不是软件模拟渲染或设备实拍照片。菜单和弹窗使用墨点截屏获取，完整墨笺图来自墨笺截图。截图时仍加载“默认设置与诊断”开发修订，最终交付版的关于和更新日志文字另有更新。

以下5张保留原始像素，只重命名以固定顺序。不对文字、数据、布局或背景进行修改。完整界面中“唤醒已读0字”是截图时状态；简介区域显示书籍现有元数据，不能据此宣称已取得网络简介。个别菜单灰显取决于当前勾选组合。
